## Regression scenarios reviewed

- Abstract/link without complete text ⇒ exclude before scoring.
- Full article but material missing proof supplement ⇒ exclude or source supplement.
- Credible fewer-than-three comparator set ⇒ possible only with documented substitute search and all roles covered.
- Exemplar creates hidden assumption/generalization ⇒ earliest affected scientific gate, not editorial PASS.
- Manuscript draft already exists ⇒ Stage 10A may be run prospectively, without retroactive claim.
- Paper's mathematical proof is valid but readers cannot identify the contribution ⇒ Stage 11 editorial REVISE, not automatic GO.
- Target journal changes ⇒ Stage 12 refresh, not silent theorem change.
