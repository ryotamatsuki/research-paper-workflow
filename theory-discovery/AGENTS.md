# Agent guidance for optional theory discovery

When the author requests TDF or research-idea discovery or refinement, start with the [current version](README.md). Read the v5.1 [master prompt](v5.1/TDF_Master_Prompt_v5.1.md), [loop protocol](v5.1/TDF_Loop_Protocol_v5.1.md), and [prompt library](v5.1/TDF_Research_Prompt_Library_v5.1.md), and use the [run ledger](v5.1/templates/Run_Ledger.md).

Use BOTH when the author leaves the mode unspecified. Respect explicit STANDARD or EPOCH requests, and continue a resumed run in its recorded mode unless the author requests a change. Keep the two candidate queues, budget allocations and verdicts separate. Keep candidate maturity, mathematical evidence, and novelty separate. Record the actual searches, the closest evidence, and any unresolved objections. When using the historical v4 model-construction catalog or v3 references, preserve their documented source-verification limits.

Present distinct candidates and the next tests to the author. After author selection, use the [handoff template](v5.1/templates/Stage0_Handoff.md) for [Stage 0](../templates/STAGE_00_IDEA_INTAKE.md). Follow the canonical research workflow for formal decisions and certification. Keep unpublished project ideas and project-specific validation in their designated project records.
