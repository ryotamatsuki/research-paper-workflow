# TDF Prompt Library v4.0

各ブロックを既存の問いカード、資料又は研究テーマと一緒に使う。
共通の出力は、使った観察、最も強い既存説明、判断が分かれる比較、出典の箇所、未確認点、次に確かめる一件。
証拠がない場合はHOLDとし、根拠を仮定して補わない。

## 問題を発見する

| 対象 | そのまま使う指示 |
|---|---|
| CE1 実在制度 | 同じ仕事を実行できる二つの組織を選び、片方だけにある活用・維持・失敗の履歴を確認せよ。どちらが効率的かを最初から決めず、その制度がないと説明できない観察を特定せよ |
| CE2 必要性 | 既存説明で現象に必要とされる条件を出典から一つ特定せよ。その条件だけを取り除いて、現象自体の定義が残る比較を作れ。別の既知機構で説明できる場合は先に記せ |
| CE3 判断と証拠 | 誰が選び、誰の何が見え、何が見えなかったかを時系列で書け。選ばれなかった事例を無作為に一部だけ追跡できる場合、次の意思決定のどの予測が変わるか問え |
| CE4 同値性 | 基準説明では同じになる二つの制度を選べ。固定する総量、独立に変える成分、制度上分離できる根拠を明示せよ。差が消える境界条件を置け |
| CE5 競合説明 | 同じ観察に合う説明を二つ作り、一つの比較で符号、順位又は発生条件が違うアウトカムを探せ。比較の妨害要因と観測の取得費用を書け |
| CE6 両立 | 各々妥当な要請を三つ以内にし、同時に実現できるか小さな例で試せ。どれか一つを外して何が可能になるか、親定理を探せ |
| CE7 構造の移動 | 別分野で似た失敗を一つ探し、決める・拒む・観察する主体と順序を写せ。写せない制約を残し、移植によって政策判断がどう変わるか問え |
| 自由記述 | 標準説明が止まった箇所の直前までを記録し、その先で誰の何が見えていないか示せ。該当するカタログ項目がなければ、操作の名前を付けず比較だけ作れ |

## 探索段階を切り出す

**テーマ探索**

> 研究テーマから、選択者、資金負担者、観測者、採否後の当事者を記せ。実在、推定、仮想を別表示し、同じ目的を実行するもう一つの制度を挙げよ。

**最も強い既存説明**

> 同じ結論を主張する文献と、別の言葉で同じ構造を分析した文献を探せ。仕事を説明する変数、予測と定義域、吟味に必要なページ、未取得箇所を記せ。抄録しか読んでいない文献の定理を補完するな。

**問いの生成**

> この制度の名称を外しても依然として説明すべきことを一文で書け。親理論による予測と別の予測、その違いで変わる判断を添えよ。観察できる差が無い場合は候補に保留理由を記せ。

**最小モデル**

> 標準モデルB0を明示し、問いたい差だけを入れたB1を作れ。厚生、利用可能な行為、情報、順序を恒等に保つ除去テストを提示せよ。除去すると別の制度に変わる箇所があれば列挙せよ。

**独立反証**

> 研究者名・手法ラベル・称賛を伏せたカードを受け取れ。最も強い親理論に写す。変数、仮定、量化、結果の対応を一行ずつ確認し、同じクラス、同じ機構、同じ結論を区別せよ。除去テストの後にも残る問いを記せ。

**対話**

> 前回の問いIDと今回の回答を読み、変わった観察、比較、状態だけを更新せよ。次回の判断に効く質問を一つ返し、データ不足なら取得又は退出の条件を記せ。

**パイプライン引継ぎ**

> 問いID、観察証拠、競合説明、理論の写像、反証、ミニモデル、未確定の命題、最も安い次手を一枚にまとめよ。Stage 0への提出用と表示し、論文としての貢献判定を未確認に置け。

```text
最も近い親理論と対応：

問いの状態 / モデルの状態 / 新規性の状態：

```
