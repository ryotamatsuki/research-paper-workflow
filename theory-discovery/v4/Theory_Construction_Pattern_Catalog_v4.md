# Theory Construction Pattern Catalog v4.0

問いを選んでから適用するL2の操作。
v3.0の番号は比較と来歴照会のために用いる。
問いと操作を分けると、同じ問いを複数の理論で検証できる。

| v3 | L2として継承する操作 | 最小の実装 | 還元・識別確認 |
|---|---|---|---|
| P01 Endogenization | 所与だった変数を行為者の選択にする | 利得、制約、時点、一つの選択 | 選択を固定した元の結果を再現する |
| P02 Unit Redefinition | 経済単位・観測単位を取り直す | 取引、個人、案件、組、組織の対応を明示 | 集計の構成と個体内の変化を分離 |
| P03 Concept Decomposition | 同じ変数に入っていた成分を分ける | 二成分を独立に割り付けるか比較する | 両成分の同時変化だけで符号を主張しない |
| P04 Hidden Function | 機能仮説を比較可能にする | 目的・反事実・代替制度・履行可能性 | 制度選択と制度機能の説明を別に試す |
| P05 Selection Feedback | 選択内生性を明示する | 参加・選別ルールと条件付き分布 | 母集団固定、未採択結果、選別を除いた比較 |
| P06 Dynamic State | 状態遷移を導入する | 二期、持越し量、更新式、移行費 | 状態が消える特殊ケースで効果が消えるか |
| P07 Rights Reinterpretation | 所有・決定・照会・開示などの権利を割当 | 平常時と例外時の決定集合、履行可能性 | 状態で誰が何を変えられるかを比較 |
| P08 Strategic Interaction | 各行為者の最適反応の相互依存を明示 | 片側固定の問題と最小ゲーム | 競争者の行動固定で結果が残るかを検査 |
| P09 Robust Bounds / Invariance | 仮定のクラスに対する境界を導出 | 許容集合、境界、達成例又は近似列 | 必要と十分、存在と全称を分離 |
| P10 Institutional Boundary | 取引の場所・参加・統治を比較 | 同じ対象と目標のもとで選択肢を変更 | 名称の違いによる見かけの差を落とす |
| P11 Equivalence Breaking | ベンチマークの同値性が崩れる最小条件を入れる | 同値性が戻るネストされた2モデル | どの定理のどの仮定かを記す |
| P12 Policy-Principle Domain Test | 政策原則を限定された定義域で試す | 政策ペア、厚生、実装、境界・逆転例 | 原則の定義域と代替政策の実現可能性を固定 |

L1に属する取引費用、逆選択、コミットメント、財産権、評判などは候補機構として出典とともに置く。
L3の問い「名目上は同じ二つの配置が、失効時にどう異なるか」に対し、P03・P07・P11を使える。
逆にP07を選んだ事実だけから、未解明の問いがあるとは判断できない。

## 選択順序

1. 問いを識別するアウトカムと介入を指定する。
2. 最も近い基準を再現し、追加する差を原則一つに置く。
3. 追加した機構と他の仮定が一緒に動いていないか確認する。
4. 競争、情報、厚生のどの主張を除去しても問いが残るか確認する。
5. 条件のスコープ、境界、反例、計算と証明の区別を台帳に反映する。

P04・P10–P12の視点がL3と似る場合、先に出典と説明の失敗点から問いの記録を作る。
L2欄は、選んだ問いの検証中に実際に動かした量やルールを報告する。
