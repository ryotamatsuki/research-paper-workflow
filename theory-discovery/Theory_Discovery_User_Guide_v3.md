# TDF v3.0 利用ガイド

## 使い方
1. Master Prompt をAIの新規チャットまたは研究リポジトリの指示ファイルへ配置する。Framework、Pattern Catalog、DB（CSVまたはJSON）を添付する。
2. 「テーマ：自治体が新品種を育成する経済的意義と有効条件。既存の公共財論を超える理論候補を探索して」のような粗い入力を渡す。
3. Phase 1〜6の出力を確認し、制度事実・先行研究・反例を吟味する。上位候補を自分で選ぶ。弱ければ再探索する。
4. 選んだ候補に限り、最小モデル、均衡、命題、比較静学、反例を求める。別セッションで独立レビューを依頼する。
5. テーマ別に候補表、文献、指紋、棄却理由、採択理由を保存する。

## 終了基準
研究アイデア探索段階は候補の比較と反証、次の判断事項が整理されれば終了。新規性の立証や論文執筆は別工程。TDFの予測性能は未検証。
