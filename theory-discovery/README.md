# Theory Discovery Framework (TDF) — optional pre-Stage-0 companion

Integration status (2026-11-16): **PARTIAL — original v3.0 package unavailable**.
TDF v3.0 is the final practical framework described in the research report dated 2026-11-15. This directory currently provides integration guidance and a clearly labeled standalone reconstruction of the discovery prompt, not the original six deliverables. Do not cite this as a verified import of those files or as validated evidence of TDF effectiveness.

## Purpose

Turn an author's research topic, institution, or policy into alternative economic explanations and research questions using historically influential theory-building moves. TDF supports iterative dialogue, not automatic paper production or one-shot theorem certification.

## Use

1. Read [MASTER_PROMPT_RECONSTRUCTED.md](MASTER_PROMPT_RECONSTRUCTED.md) and provide a research topic, motivation, supplied sources and any known closest literature.
2. Explore distinct candidate mechanisms, their conventional benchmarks and rival explanations. Prefer economically meaningful transformations rather than feature accumulation.
3. Discuss promising candidates, deepen or discard them and record unresolved prior art. A candidate may remain high-risk or no candidate may survive.
4. Only after the author chooses to initiate a project, pass the selected question, evidence and open issues to [Stage 0](../templates/STAGE_00_IDEA_INTAKE.md). Subsequent canonical stages perform their own audits.

The conceptual sequence is Theme Map → Baseline Theory Audit → Pattern Selection → Candidate Generation → Prior-Art Falsification → Value Screen → Dialogue. These are internal discovery phases, not new canonical stages.

TDF is optional. If a research question is already clear, start the existing workflow normally. [GOVERNANCE.md](../GOVERNANCE.md) and the [canonical pipeline](../THEORY_PAPER_RESEARCH_PIPELINE.md) take precedence. No Stage number, verdict, route, rollback, freeze rule, certification obligation, release or historical tag is changed. TDF output is a hypothesis, never a Stage GO, verified theorem or novelty certificate.

## Handoff and public/private separation

Record candidate ID, topic/observed facts, source access/reading depth, conventional explanation, revised question and mechanism fingerprint, closest parent theory and absorption risk, candidate result and falsifier, alternative explanations, unresolved issues, exploratory disposition, and author decision. Initialize/continue AI provenance under canonical rules. Keep actual unpublished candidate registers, project-specific source material and sensitive notes in the respective private project repositories. The workflow repository is public; it is for reusable methodology, not the owner's unpublished research.
