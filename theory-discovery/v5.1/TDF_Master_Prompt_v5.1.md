# TDF v5.1 — Master Prompt

```text
研究テーマ = 〈必須〉
観察・資料 = 〈任意〉
モード = STANDARD / EPOCH / BOTH（新規探索で未指定なら BOTH。継続時は前回台帳のモード。明示指定を優先）
目標誌・貢献類型 = 〈任意、未指定なら広い専門査読誌水準〉
探索予算 = 〈任意、Protocol 既定〉
前回台帳 = 〈継続時に添付〉

TDF v5.1 Loop Protocol と Prompt Library を適用して、研究テーマから研究開始に値する問いを発見せよ。目的は採択数の最大化でも全候補の棄却でもない。実行した検索式・版・読取深度・最強反論・差分・次の検証を記録する。実在の事実と仮想を区別し、未実施の検索・独立査読・証明を報告しない。

1. STANDARDでは論文の貢献単位を先に選ぶ。既存モデルの新命題、実質的拡張、一般化・統合、修正、制度比較・政策条件、適用上の新しい経済的含意、新機構を対等な選択肢とする。新概念・一般理論の創造は要求しない。最強先行論文の仮定・定理・限界を縦に掘り、同じモデルで未検討の結果、経済的に意味ある比較、境界、反例を探す。親理論に属するだけでは棄却しない。固定した対象と変える条件を具体化し、最小検証で何が分かるか書く。
2. EPOCHでは別の探索キューを使い、既存説明で同一視された現象の分離、隠れた前提、未知の統一原理、非自明な不可能性を問う。通常論文水準だけで通過としない。原理が必要な理由と少なくとも二つの適用場面での分岐予測を示す。BOTHでは同じ候補に採点するだけではなく、別の生成キュー・残予算・判定を管理し、取得済み文献は共用する。
3. 全候補に構造的な問い、予測差又は識別比較、B0、差分一つ、経済的根拠、最小検証、反証条件、具体的な貢献候補を登録。制度名の言い換えを統合する。L2/L4/L8（抽象構造・親理論・最近の研究）の標的検索を優先し、最も近い一次資料と比較する。各検索の実績は候補・検索式・日付・結果ID・関連性を残す。検索回数を品質の代理にしない。
4. 最強の反論を「REFUTED（証拠あり）」「AUDITABLE（限定的な検証計画あり、現状で即死とは言えない）」「FATAL_UNRESOLVED（同一命題の疑い等、先に解消が必要）」に分ける。単なる追加調査や未証明を即死とみなさず、決定的脅威を通常の残課題に格下げしない。抽象・要約だけで吸収を断定しない。既存理論に含まれることと既存結果の直接の系であることを分ける。
5. DISCOVERY＝問い候補、PROMISING＝研究投資に値する仮説、PRE-SCREEN SURVIVED＝本格事前審査を通過、HOLD＝証拠・識別等の阻害、REJECT＝特定の貢献主張が吸収又は残差なし。成熟度・処分・数学・新規性を独立記録。STANDARDのPROMISINGは新規性未確定のまま著者選択によりStage 0提出可。決定的な脅威が未分類/未解決ならHOLD。EPOCHは追加条件と本格事前審査を通過したもののみ提出可。どの通過も新規性認証ではない。
6. 棄却の単位は主張。問いが残るなら同じ文献の定義域・限界から新しい命題を作る。境界変更が結果にどう効くかを明示し、同じ主張の言い換えを復活させない。証拠不足なら保留し、他候補・別探索経路へ配分。
7. PROMISINGを得てもユーザー指定が比較探索なら両モードの探索を続け、予算内で選択肢を比較する。各ラウンド終了時には状態と次の一手を保存。予算が尽きたら正直に停止し、未完の作業は同じ台帳から再開。候補数をノルマにしない。独立した探索を実行できない場合は同一実行内の視点分離と呼ぶ。
8. 出力はモード別に最大3件、又は0件。STANDARDでは貢献型、最強先行結果、差分、検証可能な命題、反論・残課題、判断理由を示す。EPOCHでは概念の必要性と既存理論で区別できない比較を追加。研究候補の価値と証拠の充足を別に評価。著者選択なしにStage 0を開始しない。正式Stage 0/1/2/6は省略しない。
```
