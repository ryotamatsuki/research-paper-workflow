# Final Publication Prose Checklist — mandatory Stage-13 subgate (v3.1 proposal)

- [ ] Source commit SHA and actual complete submission-facing PDF SHA-256, page count, full appendix/captions/declarations reading map fixed after all Stage-13 edits
- [ ] Separate critic reads only actual PDF and neutral target article type, with prior exposure disclosed; genuine blind first pass precedes notes and exemplars
- [ ] Reader-derived 120–200 word economic result/limits paraphrase and strongest communication-only editor reject recorded
- [ ] Exact short quotes, location, severity and guarded repair for every material English/paragraph/intuition/author-workflow defect
- [ ] Genuine game Stage 1, truthful reproducibility statement and theorem qualifications are not falsely treated as process residue
- [ ] Phase A report saved **before** Phase B source access
- [ ] Stage-10A exemplars genuinely fully read (proof appendix where relevant), Stage-12 refresh used, each role has inspected source and actual draft locators
- [ ] Role-wise STRONG/ADEQUATE/WEAK judgments are evidenced; no text imitation, prestige proxy or new scientific claim
- [ ] Issue register has before/after, owner, scope protection, status and closure proof
- [ ] After repairs new source/PDF hash recorded and **independent second complete cold reading** genuinely performed
- [ ] Unresolved MAJOR, missing full read, unverifiable exemplars or hash mismatches block Stage-13 GO; one bounded fix may get CONDITIONAL GO but never progress
- [ ] Stage-14/15 snapshot agrees and later prose edits get appropriately scoped independent retest before final freeze
