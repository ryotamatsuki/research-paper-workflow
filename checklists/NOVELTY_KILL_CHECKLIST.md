# Novelty Kill Checklist

Apply this checklist to each candidate contribution separately. A project may survive while individual claims are killed.

## Exact-prior-art checks

- [ ] Is the same theorem already known?
- [ ] Is the same threshold ordering already known?
- [ ] Is the same sign reversal already known?
- [ ] Is the same organizational transition already known?
- [ ] Is the same welfare wedge already known?
- [ ] Does a close paper contain the result in an appendix or extension?

## Cosmetic-novelty checks

- [ ] Is this only a parameter rename?
- [ ] Is this only a new industry/application?
- [ ] Is this only a different functional form?
- [ ] Is this only a new label for an existing player/channel?
- [ ] Is this only a known model with current institutional vocabulary?

## Mechanical-result checks

- [ ] Does a fixed cost mechanically create the threshold?
- [ ] Does a demand intercept/market-size shift mechanically create the result?
- [ ] Does the contract assumption directly implement the desired outcome?
- [ ] Does adding one extra player mechanically create the claimed comparison?
- [ ] Does adding a state variable create only trivial history dependence?
- [ ] Does a symmetry/asymmetry assumption predetermine the ranking?
- [ ] Is the welfare difference merely transfer accounting?

## Combination-novelty checks

- [ ] Are all components already well known separately?
- [ ] Does their combination create a genuinely new strategic interaction?
- [ ] Is there a new theorem rather than just a longer model?
- [ ] Would removing one component leave the headline result unchanged?

**Rule:** known components do **not** by themselves imply that the candidate game/model is absorbed. Component overlap and game-level absorption are separate findings. Combination novelty is weak only when the combination adds no economically substantive strategic interaction or result.

## Game-architecture absorption test

For strategic/game-theoretic work, compare the candidate and closest prior models at the level of the complete game, not only ingredient-by-ingredient.

- [ ] Same economically relevant players?
- [ ] Same objective functions for each player type?
- [ ] Same strategy sets/endogenous controls?
- [ ] Same timing and commitment structure?
- [ ] Same information structure?
- [ ] Same participation/outside-option structure?
- [ ] Same endogenous allocation/sorting/choice rule?
- [ ] Same market structure and incidence of payoffs/welfare?
- [ ] Same best-response or strategic-feedback network?
- [ ] Same equilibrium concept?
- [ ] Can one prior model reproduce the candidate game through a direct relabeling, normalization, or parameter restriction?
- [ ] Alternatively, is the candidate headline result an immediate corollary of an already-solved model even if the full setup differs?

Do **not** classify a game as `EXACT PRIOR ART` or absorbed merely because different literatures separately contain its components. If reproducing the candidate requires stitching together multiple prior models with different players, objectives, strategy sets, or equilibrium feedbacks, record `COMPONENT OVERLAP` or `STRUCTURALLY VERY CLOSE` as appropriate and continue to the interaction-result test.

## Generalization / unification contribution test

A contribution may be valuable even when it deliberately extends or nests known models. Evaluate this route explicitly.

- [ ] Does the candidate nest one or more important prior models as transparent parameter restrictions or player/strategy removals?
- [ ] Does the generalized model make a strategic interaction endogenous that is absent from each benchmark?
- [ ] Does the generalized model yield a new threshold, ordering, sign reversal, equilibrium region, welfare wedge, comparative-static interaction, or conditions-for-effectiveness result?
- [ ] Are benchmark results recovered correctly when the added strategic margin is shut down?
- [ ] Does the new result disappear or materially change when an essential component is removed?
- [ ] Is the result more than “the old theorem still holds under a broader functional form”?
- [ ] Can the paper state what the general model teaches that none of the nested benchmarks can answer alone?

A clean generalization/unification that nests important prior models and generates new strategic or welfare results can qualify as a main theoretical contribution. It must not be killed solely because its ingredients are individually familiar.

## Nested-benchmark test

When the candidate is a generalization or synthesis, define the minimum benchmark games obtained by removing or fixing one strategic component at a time. For each benchmark, record:

- players removed/fixed;
- strategy removed/fixed;
- equilibrium/result recovered;
- closest prior model;
- result that exists only in the full model.

The full model earns credit only for results generated by the interaction that the nested benchmarks cannot independently deliver.

## Timing and priority checks

- [ ] Did an earlier working paper establish the result?
- [ ] Has a newer working paper appeared since the project began?
- [ ] Are working-paper and journal versions being double counted?
- [ ] Is the cited “new” paper actually older in working-paper form?

- Exact difference in welfare implication:
- Prior models nested by the candidate, if any:
- Full-model result unavailable in each nested benchmark:
- What survives if the application label is removed?:
- Classification: `EXACT PRIOR ART / STRUCTURALLY VERY CLOSE / COMPONENT OVERLAP / MERELY RELATED / POTENTIALLY NOVEL`

## Kill decision

- [ ] `KEEP AS MAIN CONTRIBUTION`
- [ ] `KEEP AS SECONDARY RESULT`
- [ ] `BACKGROUND / ROBUSTNESS ONLY`
- [ ] `KILL`

If the claim cannot be stated without relying on “we combine X and Y” or “we apply X to industry Z,” presume it is weak until a distinct interaction theorem is shown. Conversely, do not kill a candidate merely because X and Y are known separately: first determine whether the combined game creates a strategically non-equivalent equilibrium problem and a new result.
