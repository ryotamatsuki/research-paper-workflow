# Retailer as Service Infrastructure — Worked Case

Historical research label: Legacy retail-channel redesign, historical Stages 0–3

Canonical workflow mapping: Stage 1 audit → Stage 2 novelty gate → Stage 3 mechanism search → Stage 4 minimal model → Stage 5 hardening → Stage 6 novelty re-kill, with a Stage 3–5 loop for the dynamic branch

Research status: `CONDITIONAL GO`; canonical Stage 7.5 has not been passed and theory is not frozen

## Origin

The case began from a roughly sixteen-year-old undergraduate seminar paper, `家電量販店と系列店 ～家電の流通についての分析～`. The legacy model itself was not treated as a manuscript to modernize. The retained object was the economic question behind it.

## Original phenomenon

Why can a manufacturer continue to support a costly local affiliated dealer network when efficient large-scale retail channels are available?

The first modern reinterpretation was `Retailer as Brand-Specific Service Infrastructure`: a local dealer may create service value that extends beyond its own product sales.

## Research path

```text
Legacy model
  → static service spillover
  → static service contract
  → installed base only
  → installed base + legacy service capital
```

The path is intentionally not presented as linear progress toward a predetermined theorem. Each transition followed a diagnosed failure and allowed one targeted modification.

## Current state

The static sales-margin-only model was rejected as a publication baseline. The static service-contract repair was also rejected because a service-only former dealer became economically indistinguishable from an ordinary third-party service provider. Installed base alone explained persistence of service demand but not provider identity. The surviving branch introduces manufacturer-specific legacy service capability and produces a candidate dynamic vertical mechanism, but its accumulation law remains insufficiently microfounded.

Accordingly, the current historical verdict is `Stage 3 CONDITIONAL GO`, not a paper-level `GO`.

## Why this case exists

This example documents failed branches and disciplined pivots. Its reusable value is the sequence:

`diagnosed failure → one targeted modification → new kill test`.

It is not a production-paper repository, a final bibliography, a symbolic reproducibility archive, or evidence that the surviving model is publication-ready.
