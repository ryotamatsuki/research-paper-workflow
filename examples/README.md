# Worked examples

Historical research cases used to test and illustrate the workflow. Examples are subordinate to `GOVERNANCE.md`, the canonical pipeline, stage templates, and checklists; they do not define canonical rules.

A worked example should preserve rejected paths, negative results, evidence limits, and the reason each subsequent modification was permitted. Do not copy a case-specific model into a new project; reuse the decision process.
